# Architecture
Rust workspace: core timeline and command model, future media, renderer, encoder and workflow crates. Tauri + React will call typed commands; the core must not depend on UI. Asset IDs refer to immutable source media. Initial timebase is 240000 ticks/s; arbitrary VFR PTS conversion must be explicit. Project schema version 1 is provisional. Preview and export should share a render graph. FFmpeg subprocesses must use argument arrays. Hardware encoding is capability-detected, with CPU fallback. Remote development uses GitHub; remote editing later uses authenticated private networking, not public ports. No media or credentials in Git.
