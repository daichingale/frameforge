# FrameForge

動画のカット、字幕の追加、音声付きの書き出しをブラウザ内で行う動画エディターです。動画素材は端末内で処理します。

**[FrameForge をブラウザで開く](https://daichingale.github.io/frameforge/)**

## ローカル開発用の起動

Node.js 22 以降が必要です。リポジトリを取得し、直下で次を実行して [FrameForge](http://127.0.0.1:4173) を開きます。追加パッケージのインストールは不要です。

```sh
node serve.mjs
```

## 編集

1. 「メディア」の「追加」で動画を選ぶか、メディア欄にファイルをドロップするとタイムラインに並びます。重い素材は「軽量化」で再生用の低解像度コピーを作れます。作成にはおおむね素材の再生時間がかかります。一時停止中の位置合わせと最終書き出しには元動画を使います。
2. タイムラインの目盛りを動かして再生位置を調整します。クリップ本体をドラッグすると順番が替わり、端のハンドルをドラッグするとトリムできます。拡大や全体表示もできます。
3. 指定区間を取り除くには、開始点で `I`、終了点で `O` を押して「区間を詰めて削除」を選びます。後続の映像と字幕は削除した長さだけ前に移動します。字幕はタイムライン上から選択できます。
4. 「動画を書き出す」で横型16:9か縦型9:16の解像度と形式を選びます。素材と出力の縦横比が異なる場合は余白を入れます。開始・終了の秒数を指定すると、編集データを保ったまま必要な区間だけを書き出せます。使える形式はブラウザによって変わります。書き出しはおおむね選んだ区間の長さかかるので、処理が終わるまでタブを開いてください。

「保存」は編集内容を JSON として保存します。別の端末で続きを編集するときは JSON と元の動画ファイルを移し、「開く」の後に「素材を再リンク」で元動画を選びます。軽量プレビューは開いているタブ内で利用できます。

タイムラインの分割は `S`、プロジェクトの保存は `Ctrl+S`、元に戻す操作は `Ctrl+Z`、やり直しは `Ctrl+Y` で実行できます。
